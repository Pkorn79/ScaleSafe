User Guide

A practical operating guide for ScaleSafe private beta merchants.

1. Install and provisioning

  1. Install ScaleSafe from the GoHighLevel Marketplace or beta install link.
  2. Open ScaleSafe inside GoHighLevel and confirm SSO login works.
  3. Open Settings and run Provisioning Health.
  4. Confirm merchant status, webhook secret, custom values, contact fields, trigger subscriptions, and payment settings.

2. Connect payment settings

Stripe

Connect the merchant's Stripe account, enable the needed payment methods in Stripe, and test with Stripe sandbox before live use.

NMI

Add the merchant's NMI credentials, confirm the account can process live transactions, and make sure Query API permission is enabled so vaulted card metadata can populate.

3. Build offers

  1. Create an offer and choose full enrollment or quick checkout.
  2. Set pricing: one-time, installments, subscription, or PIF/installment option.
  3. Add terms, refund language, milestones, pulse cadence, tags, dual pricing, and one-time checkout add-ons where needed.
  4. Save, reload, and open the public checkout/enrollment link to confirm the client-facing page is correct.

4. Run clients through checkout

For full enrollment, clients complete contact details, offer review, terms/signature, then payment. For quick checkout, the client pays from the shorter hosted page. For quick manual sale, the merchant enters the card and can optionally send the enrollment packet link afterward.

5. Verify workflows

  • Payment Received: receipt/payment confirmation only.
  • Send Enrollment Link: enrollment packet link only.
  • Enrollment Complete: welcome/access only after terms/signature/enrollment completion.
  • Payment Failed: failed payment/dunning path.
  • Refund Processed: refund confirmation.
  • ScaleSafe App Event: payment reminders and pulse check-ins.

6. Evidence and defense

Use the client profile to review evidence, communications, payment records, milestones, pulse check-ins, and defense packets. Defense workflows should be reviewed before submission to a processor or bank.
