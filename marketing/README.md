# ScaleSafe public site

This folder contains the static public site intended for `https://scalesafe.app`.

## Pages

- `index.html` - landing page / private beta CTA
- `privacy.html` - privacy policy
- `terms.html` - terms of service
- `support.html` - support hub
- `guide.html` - user guide
- `troubleshooting.html` - troubleshooting guide

## Launch notes

- Host the folder contents at the domain root so `/privacy.html`, `/terms.html`, and `/support.html` match the Marketplace listing URLs.
- Final legal review is still recommended before treating the policy/terms pages as final.
- If a chatbot is added later, connect it to the support content first and keep it away from payment/legal promises.
